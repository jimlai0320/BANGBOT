BANG! 骰子版 v0.7.0 - 完整修正版（基於 v0.6.9）

一、死亡/結束回合修正
- 目前擲骰者因箭雨或 3 顆炸藥受到致命傷害，會立即判斷勝負。
- 如果比賽沒有結束，自動結束死亡玩家的回合，跳到下一位存活玩家。
- 下一位若為電腦，BOT 會自動繼續讓電腦行動。
- 3 人局死亡時，也會依目標/決鬥規則處理。

二、查看角色按鈕互相干擾修正
- 原本群組「👀 查看角色」會編輯同一則群組牌桌的按鈕，
  多個玩家同時查看時會互相切換、跳來跳去。
- 現在按下後，在個人的 BOT 私訊中建立獨立的角色清單，
  每人可點選玩家查閱公開角色能力；不再修改群組牌桌按鈕。
- 同一玩家重複查詢時，更新自己的私訊清單，避免一直新增訊息。
- 如果未向 BOT 按過 Start 或封鎖 BOT，群組會回覆簡短公開角色摘要，
  請先到 BOT 私訊輸入 /start 才能用完整角色查詢。
- 「我的角色」「我的身分」仍僅自己可查看；其他玩家秘密身分不公開。
- 只有目前遊戲參與者才能查看角色詳情；三人局角色身分公開，警長公開。

三、保持不變
- 3～8 人牌桌版型/圓桌射擊距離、各角色卡、剪影身分卡、
  擲骰動畫、file_id 快取、原身分目標規則均保留。

四、使用方法
1. 關掉舊 BOT 主控台（避免兩個實例使用同一 BOT_TOKEN）。
2. 將新版 ZIP 解壓縮到新的資料夾。
3. 使用 SET_TOKEN.bat 設定 BOT Token，執行 START.bat。
4. 開局前，真人玩家先向 BOT 私訊 /start。
5. 群組中「查看角色」會把公開角色清單送到自己的 BOT 私訊。
