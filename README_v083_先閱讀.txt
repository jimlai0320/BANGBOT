BANG! 骰子版 Telegram BOT — v0.8.3 老酒館更新包

【如何更新】
1. 先關閉目前執行中的 BOT 黑色視窗。
2. 將本 ZIP 解壓，把所有檔案複製到原本 v0.8.2 或 v0.8.2.1 的資料夾，選擇覆蓋。
   bot.py 必須與原本 START.bat、assets 資料夾放在同一層。
3. 執行 START.bat。原本 .env 與 BOT_TOKEN 保留，不需要重填。
本包包含累積程式修正；沒有重新打包 230 MB 的原有美術，必須配合原本完整包使用。

【開始玩新功能】
群組輸入 /newgame saloon。
大廳原本預設勾選「酒館特殊骰」和「酋長之箭」。
請再開啟「新增8位角色」及「特殊身分」。
加入至少5位玩家後，可以再開啟「鬼魂模式」。
3～8位玩家可以混合真人與AI；每位真人先到BOT私訊按Start。
仍可使用 /newgame 玩原版。

【本次完成】
• 8位新角色：六骰能力、延後拿箭、轉交箭、搶酋長箭、射擊減傷、準心回血、代受傷害。
• 9種特殊身分：熊警長、好人、醫生、法官、賭徒、壞人、醜人、惡魔右手、惡魔左手。
• 特殊身分每局一次；群組有3秒反應窗口，搶到發動權後共10秒完成細節選擇。
  若尚未正式發動就超時或放棄，不消耗能力。法官成功取消後，雙方能力均消耗。
• 鬼魂：第一名非警長淘汰者成為鬼魂，擲2顆普通骰，最多重擲2次；給出單/雙標記。
  標記指定收件人下回合首擲的1或2顆普通骰；鬼魂不計射程，原角色與特殊身分能力停用。
  叛徒鬼魂依5/6/7/8人局改為歹徒/副警長/歹徒/副警長。
• 支援2、5、6顆骰的牌桌與群組選骰；新骰用現有美術製作短動畫。
• 保留原版座位與素材，新增角色頭像、角色卡、特殊身分卡、鬼魂顯示均接上。
• AI與真人使用同一個擴充結算流程；一般選擇50秒，能力細節10秒，逾時有預設處理。
• 賭徒以交易快照忽略最後一擲：之前各擲已結算效果保留，最後一擲不重複扣血。
• 技能按鈕核對玩家、遊戲識別、窗口編號及期限，舊訊息、他人及重複按鈕無法重複發動。

箭池守恆、六骰、角色能力、玩家權限、過期按鈕、共用10秒時限。

可雙擊 CHECK_ALL.bat 在自己的電腦再執行全部測試。
