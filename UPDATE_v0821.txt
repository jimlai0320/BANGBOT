BANG! 骰子版 v0.8.2.1 修正包

安裝：
1. 關閉目前執行中的 BOT 視窗。
2. 將本包的 bot.py、game_engine.py、ai.py 複製到原本 v0.8.2 資料夾，選擇覆蓋。
   必須放在 START.bat 同一層；不用修改 .env 或 Token。
3. 執行原本 START.bat。群組用 /newgame 玩原版，或 /newgame saloon 玩特殊骰＋酋長箭。
4. 如果要在電腦執行全部離線測試，將附帶 TEST_v0821_regressions.py 和 CHECK_ALL.bat、run_checks.py 也放入同一資料夾，雙擊 CHECK_ALL.bat。

本次修正：
- 格林機槍正確歸還射手持有的酋長箭（含只有酋長箭、沒有普通箭的情況）。
- 蘇西不再把雙準心當成沒有準心而錯誤回血。
- 斯萊布可用雙啤酒其中一個符號加倍一個準心效果；雙準心可加倍其中一次射擊。
- 真人能力按鈕與 AI 使用一致的符號計數。
- 射擊依準心 1、準心 2 的順序處理。
- 舊狀態只有骰面、沒有骰子種類時，重擲可恢復普通骰資料，避免 IndexError。
- 重擲忽略越界及不能重擲的炸藥；沒有合法選取時不消耗擲骰次數。
- 第一擲入口只在回合開始有效，不能重複重置正在進行的骰面。
- 斷箭選擇完後從中斷位置繼續，處理完所有斷箭才處理子彈；避免後續即時效果被跳過。

檢查結果：
- 既有 selftest 與全部 TEST_*.py，加上本次邊界案例：17 個程式全部通過。
- 其中老酒館壓力測試為 3～8 人各 15 場，共 90 場完整 AI 對局。
- 原版素材 SHA256 驗證通過；本包未包含或替換美術。
- 全部主要 Python 模組語法檢查通過，實際依賴安裝後 bot 可載入。
- Linux Python 3.12 離線驗證；未連線 Telegram，未實測 Windows 啟動。

功能現況（不能當成完整老酒館擴充）：
可玩：原版、酒館特殊骰、酋長箭。
未開放：8 位新角色、9 種特殊身分、鬼魂模式。
特殊骰動畫仍沿用原版 MP4，正式結果使用老酒館骰面。
截圖提到的鬼魂及特殊身分後續工作不在上傳的 v0.8.2 內。
